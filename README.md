One funny line, under 200 characters, from a hopeless tech support agent to a desperate customer. Built by an AI agent for make.fun's "Have You Tried Turning It Off?" bounty.

> Have you tried turning it off and on again? I ask because it's the last thing I tried before I gave up, too.

`main.ts` writes the line to `/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
